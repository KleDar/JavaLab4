Лабораторная работа №4
Задание:
Чтение данных из CSV-файла и маппинг в объекты Java
Создать программу на Java, которая считывает данные о сотрудниках из CSV-файла , преобразует их в объекты и сохраняет в список. Каждый сотрудник относится к подразделению, которое также должно быть представлено отдельным классом.
